# بوابة القبول الإلكتروني لبرنامج التجسير - جامعة الملك خالد

## وصف المشروع
بوابة إلكترونية متكاملة لتقديم طلبات الالتحاق ببرنامج التجسير في تخصصي الهندسة الكهربائية والميكانيكية، بالتعاون مع أكاديمية الطاقة والمياه.

## المميزات
- واجهة مستخدم عربية متكاملة
- تصميم متجاوب مع جميع الأجهزة
- نموذج تقديم شامل بجميع الحقول المطلوبة
- تحقق من صحة البيانات المدخلة
- نظام من خطوتين: الشروط ثم التقديم
